9-Module Isolation Rules — Permanent
No module imports another module's source. Contract-first, always.
1
PostgreSQL is the only source of truth. No Redis key, no in-memory object, no cache value is authoritative for workflow state or invoice data.
2
XState is stateless between requests. createActor → send event → get snapshot → discard. Never kept alive. Phase I: inline dev path. Phase II: real service.
3
State + history + audit in ONE transaction. workflow_state, workflow_state_history, audit_events commit together. Split commit = data inconsistency = production incident.
4
n8n fires AFTER PostgreSQL commits. Never inside the transaction. If n8n is down, the invoice state is correct. BullMQ retries the notification independently.
5
State regression guard enforced. _STATE_ORDER list prevents any backward transition (e.g. extracted → received after n8n double-fire). Logged at WARNING level, never silently swallowed.
6
Bootstrap latch before autosave. bootstrapReady flag must be true AND activeProjectId must be set before saveActiveWorkflow() fires. Prevents autosave race on startup.
7
Workflows require a Project. addWorkflow() throws NO_PROJECT if activeProjectId is null. All 4 IngestionHub modes gate on project. Autosave includes project_id in every PUT payload.
8
Simulation required before activation. DB trigger check_workflow_simulation_pass() blocks INSERT with active=TRUE unless a workflow_simulation_runs record with passed=true exists.
9
No DELETEs on workflow or audit tables. REVOKE DELETE enforced at PostgreSQL role level. Append-only by design. Only a privileged archive job may move rows after retention period.
10
No circular store imports. useWorkflowStore imports useProjectStore via .getState(). useProjectStore never imports useWorkflowStore. Shell coordinates both. Validated: smoke test passes 15/15.
